# pachinko

Browser pachinko machine - physics simulation with Three.js

The October 26 timing update keeps play speed consistent across display refresh
rates and prevents screen shakes from leaving the board shifted. See
[release notes](RELEASE_NOTES.md) and [gameplay checks](tests/gameplay/README.md).
